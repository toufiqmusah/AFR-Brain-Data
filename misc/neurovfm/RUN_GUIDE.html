Running NeuroVFM Training on Lightning AI

1. Upload Files

neurovfm/            # upload this whole folder
├── prepare_data.py
├── train.py
├── model/neurovfm.py
└── RUN_GUIDE.html

dataset/             # your skull-stripped MRI data
participant-info.tsv # subject labels

2. Install Dependencies

pip install torchio nibabel pandas scikit-learn
# NeuroVFM needs flash-attn 2.6.3 + git clone install:
git clone https://github.com/MLNeurosurg/neurovfm.git
cd neurovfm && pip install -e . && cd ..

3. Edit Paths in prepare_data.py

Lines 262 & 268 — change to your Lightning AI paths:

--data-root        path to your dataset folder
--participant-tsv  path to participant-info.tsv

4. Run

# Step 1 — scan data, create splits
python prepare_data.py \
  --data-root /path/to/dataset \
  --participant-tsv /path/to/participant-info.tsv \
  --output-dir ./output

# Step 2 — train attention-pooling classifier (5-fold CV)
python train.py \
  --splits ./output/splits.json \
  --output-dir ./output \
  --data-root /path/to/dataset

# Step 3 (optional) — run attention rollout explainability
python eval_gradcam.py \
  --splits ./output/splits.json \
  --checkpoint ./output/fold1_best.pt \
  --output-dir ./output/gradcam \
  --data-root /path/to/dataset

5. Output Files

output/
├── manifest.json           dataset summary
├── splits.json             fold assignments
├── raw_tokens.pt           cached token sequences (delete to re-extract)
├── results.csv             per-fold metrics
├── results.json            aggregated results
├── fold1_best.pt           best classifier weights (fold 1)
├── fold2_best.pt
├── ...
├── gradcam/
│   ├── sub-XX_saliency.pt  attention rollout saliency per test subject
│   └── ...

6. Verify

python prepare_data.py --data-root /path \
  --participant-tsv /path --output-dir ./output

Expected: ~63 subjects, ~114 T1w axial scans
